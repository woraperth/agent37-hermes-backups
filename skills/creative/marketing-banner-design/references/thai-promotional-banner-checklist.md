# Thai Promotional Banner Checklist

Use this reference after drafting the copy and again after rendering.

## Copy lock

- Audience/eligibility: say who can use the offer.
- Benefit: state the discount amount and what it applies to.
- Price: show original and final price consistently.
- Code: use a conspicuous placeholder until the real code exists.
- Deadline: include exact local date and time.
- URL: preserve the supplied URL exactly.

## Suggested Thai hierarchy

```text
นักเรียน DataTH
รับส่วนลดคอร์ส Vibe Coding เพิ่มอีก 400 บาท
4,900 บาท → 4,500 บาท
ใช้โค้ด: XXXX
หมดเขต 23:59 น. ศุกร์ 21 สิงหาคม 2026
```

Keep the full explanation in the email. The image should be scannable rather than paragraph-heavy.

## Render check

1. Confirm the font has Thai glyphs, including tone marks and vowels.
2. Render to the final PNG/JPG format.
3. Inspect the actual raster output, not just the source SVG/HTML.
4. Check the headline, prices, code, deadline, and URL one by one.
5. Check contrast and clipping at normal display size.
6. If Thai text disappears, switch to a confirmed Thai-capable font or a raster text workflow before delivering.

## Delivery note

Tell the user which fields remain placeholders and attach the actual image. Do not imply that a placeholder coupon code is ready for sending.
