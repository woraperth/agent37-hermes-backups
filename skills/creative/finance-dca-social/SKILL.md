# Finance Social Media Tips (class‑level)

## Goal
Create a short (≤280 characters) post that:
* explains a finance idea in plain language,
* mixes Thai and English naturally,
* uses emojis (≈0.7 emoji per tweet),
* includes up to two hashtags (one Thai, one English optional),
* ends with a brief CTA (e.g., “ลองดู” or “แชร์เลย”),
* follows a single‑paragraph format.

## Style guidelines (derived from user feedback)
| Element | Guideline |
|---------|-----------|
| **Length** | Aim for 150‑180 characters; never exceed 280. |
| **Tone** | Conversational, upbeat, playful; sprinkle Thai interjections (เช่น `กกก`) and emojis. |
| **Language mix** | Start Thai, sprinkle English keywords (AI, DCA, ETF, etc.). Keep ≥70 % Thai characters, ≤30 % English. |
| **Emojis** | 1 emoji per 2‑3 sentences, total ≈0.7 emoji per tweet. |
| **Hashtags** | Max 2; preferably one Thai (`#การเงิน`) and one English (`#Finance`). |
| **CTA** | End with a short prompt like “ลองทำดู!” or “แชร์เลย”. |
| **Formatting** | Single paragraph; no line breaks unless separating a headline. |

## Construction steps
1. **Pick the core benefit** (e.g., why DCA works).  
2. **Write a Thai hook** (one sentence).  
3. **Insert the key English term** (optional).  
4. **Add an emoji matching sentiment**.  
5. **Add a tiny concrete example** (optional).  
6. **Append hashtags** (≤2).  
7. **Finish with a CTA**.  
8. **Count characters**; trim if > 280.

## Pitfalls to avoid
* Over‑technical jargon – keep it lay‑person friendly.
* More than two hashtags – looks spammy.
* Uneven language mix – avoid English‑only sentences.
* Exceeding character limit – URLs count as 23 characters.
